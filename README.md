## 🔍 Overview

This repository contains a curated portfolio of **five applied mini-projects** focused on  
**Natural Language Processing (NLP), Machine Learning, and Strategic Analytics**.

All projects are uploaded as **ZIP repositories** and follow a **consistent internal structure** including:
- dataset handling  
- preprocessing  
- modeling  
- evaluation  
- documentation  

---

## 📂 Mini-Projects Included

### 🟢 1. AI-Driven Sentiment Classification (E-Commerce)

This project focuses on **automating sentiment analysis** for customer product reviews in an e-commerce setting.

Work includes text cleaning, feature engineering, TF-IDF representation, and word embeddings.  
Multiple machine learning models were trained and compared for **multi-class sentiment prediction**.

**Models used:** Logistic Regression, Naive Bayes, Random Forest, XGBoost  

---

### 🟢 2. Semantic Word Embeddings – Word2Vec & GloVe

This project explores **semantic understanding of text** beyond keyword-based methods.

Custom Word2Vec models were trained on domain-specific corpora and compared against **pre-trained GloVe embeddings**.  
The project evaluates contextual similarity and semantic relationships between words.

**Libraries used:** Gensim, NLTK, spaCy  

---

### 🟢 3. Multi-Class News Article Classification

This project aims to automatically **classify news articles into multiple categories** such as Technology, Business, and Sports.

Text preprocessing and TF-IDF vectorization were applied, followed by **multi-class classification using Support Vector Machines (SVM)**.

---

### 🟢 4. Strategic Business Analysis – Innovation at Apple

This is a **non-technical strategic analytics project** analyzing Apple’s innovation-driven organizational structure.

The study focuses on:
- Functional organizational design  
- Leadership and decision-making culture  
- Cross-functional collaboration  
- Innovation strategy  

The analysis is based on real-world case study methodology.

---

### 🟢 5. Restaurant Review Sentiment Analysis

This project performs **binary sentiment classification** on restaurant reviews for the hospitality industry.

Text normalization techniques such as stemming and Bag-of-Words were applied.  
A **Multinomial Naive Bayes** model was used to classify reviews as positive or negative.
