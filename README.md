## 🔍 Overview

This repository contains a curated portfolio of **five applied projects** focused on **Natural Language Processing (NLP), Machine Learning, and Strategic Analytics**.
The projects emphasize **real-world problem solving, clean implementation, and actionable insights**, making them suitable for industry-oriented roles.

---

## 🎯 Key Highlights

* Real-world **sentiment analysis and text classification**
* Semantic understanding using **Word2Vec and GloVe**
* Machine learning models for **binary and multi-class classification**
* Strategic business analysis using **case-study methodology**

---

## 📂 Projects

### 🟢 1. AI-Driven Sentiment Classification (E-Commerce)

**Objective:** Automate sentiment detection for customer reviews.

**Key Work:**

* Text preprocessing and feature engineering
* TF-IDF and word embeddings
* Multi-class sentiment classification

**Models:** Logistic Regression, Naive Bayes, Random Forest, XGBoost

---

### 🟢 2. Semantic Word Embeddings (Word2Vec & GloVe)

**Objective:** Capture semantic meaning beyond keywords.

**Key Work:**

* Custom Word2Vec training
* Comparison with pre-trained GloVe embeddings
* Context similarity evaluation

**Tools:** Gensim, NLTK, spaCy

---

### 🟢 3. Multi-Class News Article Classification

**Objective:** Automatically categorize news articles into topics.

**Key Work:**

* Text preprocessing and TF-IDF vectorization
* Multi-class classification using SVM

**Categories:** Technology, Business, Sports, etc.

---

### 🟢 4. Strategic Analysis: Innovation at Apple

**Objective:** Analyze Apple’s organizational structure and innovation strategy.

**Focus Areas:**

* Functional organizational design
* Leadership and decision-making culture
* Cross-functional collaboration

---

### 🟢 5. Restaurant Review Sentiment Analysis

**Objective:** Generate sentiment insights for the hospitality industry.

**Key Work:**

* Text normalization using stemming
* Bag-of-Words feature extraction
* Binary sentiment classification

**Model:** Multinomial Naive Bayes
